# Majadigi Mobile

[Majadigi (Majapahit Digital)](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://majadigi.jatimprov.go.id/&ved=2ahUKEwiVoOKkveKTAxVkumMGHfVMBd8QFnoECBwQAQ&usg=AOvVaw1fXeu-_W_dF0ISocTHaaRA) 
Mobile is a SuperApp integrated with Hundreds of Government Services across 
East Java. Exists as a One-Stop solution for multiple needs, 
now packed in mobile version.

*Built with Flutter for IoS and Android. 

## Requirement

Guide to setup this project for developers

General Requirement:
- Flutter SDK (v3.18.0-18.0.pre.54, or as of 10th April 2026, v3.41.2)
- Dart (Built-in Flutter SDK, v3.11.0)
- Git CLI

It is very recommended to use [Android Studio](https://developer.android.com/studio) 
to help development process and setting up emulator 
or other dependencies

Project Requirement is set in [pubspec.lock](pubspec.lock)

## Getting Started

Clone this repository:
```
git clone https://github.com/Majadigi-UB-Kelompok-10/majadigi-flutter-app.git
```

Clean & Fetch Flutter Pub Packages:
```
flutter pub cache clean
flutter pub get
```
Verify Flutter SDK if needed:
```
flutter doctor -v
```

Run this project:
```
flutter run
```

Run necessary code generation:
```
dart run build_runner build
```

If you are actively contributing, run this:
```
dart run build_runner watch -d
```
